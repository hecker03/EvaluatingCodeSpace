# 🎯 Project Objective: Assignment Submission & Evaluation Platform
## Overview
This platform enables instructors to create programming assignments with structured test cases, and allows students to submit code for automated evaluation. It integrates with RapidAPI's Judge0 CE for real-time code execution and feedback.
## Goals
- ✅ Modular assignment creation with metadata and test cases
- ✅ Student-friendly submission interface with syntax checking
- ✅ Automated evaluation against instructor-defined test cases
- ✅ Instructor dashboard for reviewing submissions and grading
- ✅ Draft-saving and resubmission control for students
## Key Features
- **Instructor Flow**
  - Create/edit assignments with JSON-based test cases
  - View all student submissions
  - Review and grade with feedback
- **Student Flow**
  - Submit code in Python, C++, or Java
  - Save drafts before final submission
  - Receive syntax feedback and test verdicts
- **Evaluation Engine**
  - Uses Judge0 CE via RapidAPI
  - Polls for execution results
  - Compares actual vs expected output
  - Displays verdicts per test case
## Technologies Used
- **Backend**: Flask, SQLAlchemy
- **Frontend**: HTML, CSS, Jinja2 templates
- **Execution API**: Judge0 CE via RapidAPI
- **Database**: SQLite/PostgreSQL (configurable)
## Future Enhancements
- 🔒 Instructor-controlled visibility of test cases
- 📊 Auto-grading and analytics dashboard
- 🧪 Support for custom input/output validators
- 🧠 ML-based feedback suggestions
## Status
✅ Core flows implemented and tested
⚠️ Minor verdict rendering issues under review
🚀 Ready for classroom pilot
